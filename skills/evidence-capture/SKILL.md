# Evidence Capture

## Purpose

Prevent strong work from becoming impossible to demonstrate later.

## Use when

- a milestone is completed
- proof-of-work contains evidence gaps
- an old implementation is about to be replaced
- before production migration
- before a redesign overwrites the old state
- before closing a client project

## Evidence types

Look for:
- before/after screenshots
- responsive views
- commits/diffs
- build/test results
- benchmarks
- staging/live URLs
- architecture notes
- technical decisions
- issue/task completion
- CMS/admin evidence

## Procedure

For each meaningful achievement:
1. identify the useful future claim
2. identify existing evidence
3. identify the smallest missing proof
4. propose one capture action
5. evaluate production/privacy risk
6. do not perform risky capture without approval

Priority means urgency before evidence disappears, not quality of work.

Never capture credentials, unnecessary personal data, private tokens, or confidential material without authorization.
